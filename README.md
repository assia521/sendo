# Sendo

مساحة اجتماعية بسيطة باللغة العربية لمشاركة الأفكار والصور والفيديو والتسجيلات الصوتية. صُمّمت للهواتف أولاً بألوان البرتقالي المحروق والرمادي، ولا تحتاج إلى أدوات بناء أو تثبيت حزم.

## تشغيل سريع

1. افتح `index.html` في المتصفح لمعاينة الواجهة. في وضع المعاينة تحفظ المنشورات على هذا الجهاز فقط؛ لا تتوفر فيه الحسابات الحقيقية ولا رفع الوسائط إلى الإنترنت.
2. لتشغيل الموقع مع Supabase، أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com).
3. من لوحة Supabase افتح **SQL Editor**، والصق محتوى [`supabase/schema.sql`](supabase/schema.sql) ثم اضغط **Run**.
4. من **Project Settings → API** انسخ **Project URL** و **anon/public key**. افتح `config.js` وضع القيم بين علامتي الاقتباس:

   ```js
   window.SENDO_SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
   window.SENDO_SUPABASE_ANON_KEY = 'YOUR-ANON-PUBLIC-KEY';
   ```

   استخدم مفتاح `anon` أو `publishable` العام فقط. لا تضع مفتاح `service_role` في صفحة المتصفح أبداً.

5. ارفع مجلد `sendo` إلى استضافة صفحات ثابتة، أو شغّله عبر خادم ملفات ثابت محلي. فتح `index.html` مباشرة مناسب للمعاينة؛ بعض المتصفحات تتطلب `localhost` أو HTTPS للوصول إلى الميكروفون.
6. سجّل حساباً من زر الحساب. إذا كان تأكيد البريد مفعّلاً في إعدادات Supabase، افتح رسالة التأكيد قبل تسجيل الدخول.

## ما يتضمنه المشروع

- `index.html` — الصفحة والواجهات.
- `style.css` — الألوان والتنسيق المتجاوب للهواتف والحواسيب.
- `app.js` — الحسابات، المنشورات، البحث، الإعجاب، الحفظ، المشاركة، رفع الملفات والتسجيل الصوتي.
- `config.js` — مكان إعداد رابط Supabase والمفتاح العام.
- `supabase/schema.sql` — الجداول والمحفزات وسياسات الوصول وسياسات تخزين الوسائط.

## إعداد التخزين والأمان

ينشئ ملف SQL مساحة تخزين عامة باسم `sendo-media` بحد أقصى 50 ميغابايت للملف. يستطيع الجميع مشاهدة المرفقات العامة، بينما يتطلب رفع الملفات تسجيل الدخول ويحفظ المستخدم ملفاته ضمن مجلد بمعرّف حسابه. قواعد RLS في الملف تحمي المنشورات والإعجابات والملفات الشخصية. راجع حد الحجم وأنواع الوسائط وسياسات العرض قبل استخدام الموقع على نطاق عام.

**خصوصية:** المنشورات والملفات في هذه النسخة عامة للمشاهدة. لا تنشر معلومات شخصية أو ملفات خاصة. وضع المعاينة يحفظ بياناته في `localStorage` على المتصفح، ويمكن مسحها بحذف بيانات الموقع.

## ملاحظات

- الصوت يُسجل من ميكروفون الجهاز عبر واجهات المتصفح؛ يتطلب إذن الميكروفون واتصالاً آمناً (`https://` أو `localhost`).
- ميزة المشاركة تنسخ رابط الصفحة مع معرّف المنشور إلى الحافظة.
- المرفقات المسموح بها: صور JPEG وPNG وWebP وGIF، فيديو MP4 وWebM، وصوت WebM وOGG وMP4 وMP3. يعتمد التسجيل الفعلي على الصيغ التي يدعمها المتصفح.
- الحسابات الحقيقية وإعجاباتها تحتاج إعداد Supabase؛ من دون الإعداد يبقى المشروع في وضع المعاينة المحلية.
