# Sendo

موقع تواصل عربي خفيف لمشاركة المنشورات والوسائط والتسجيلات الصوتية، مع مراسلة خاصة بين الحسابات.

## تشغيل النشر والمراسلة عبر الإنترنت

1. أنشئ مشروعاً على [Supabase](https://supabase.com).
2. افتح **SQL Editor** في لوحة المشروع، وشغّل محتوى `supabase/schema.sql`. يهيئ الجداول وقيود الوصول ويضيف جدول الرسائل الخاصة.
3. من **Project Settings → API** انسخ **Project URL** و **anon/public key** إلى `config.js`:

   ```js
   window.SENDO_SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
   window.SENDO_SUPABASE_ANON_KEY = 'YOUR-ANON-PUBLIC-KEY';
   ```

   لا تضع مفتاح `service_role` في ملفات الموقع.

4. ارفع مجلد المشروع إلى استضافة مواقع ثابتة أو شغله على `localhost` أو HTTPS. افتح الموقع، أنشئ حساباً، ثم سجّل الدخول. المراسلة الخاصة تحتاج اتصالاً بـ Supabase.
5. ابحث بالاسم أو اسم المستخدم من زر **المراسلة الخاصة**، اختر الحساب، ثم أرسل الرسائل. لا يرى الرسائل إلا مرسلها ومستلمها بحسب سياسات قاعدة البيانات. شاشة المحادثة تحدّث الرسائل الجديدة دورياً.

إذا فعّل Supabase تأكيد البريد، أكّد عنوانك قبل تسجيل الدخول. ظهور حالة **معاينة محلية** يعني أن URL والمفتاح غير مضبوطين: المنشورات النصية تحفظ على هذا الجهاز ولا يراها الآخرون، كما لا تعمل الحسابات أو الرسائل الخاصة حتى تضيف الإعدادين أعلاه.

## الملفات والميزات

- `index.html`, `style.css`, `app.js`: الصفحة العربية، التصميم المتجاوب، النشر والبحث والإعجاب والحفظ والمشاركة والمراسلة.
- `config.js`: بيانات الاتصال العامة بـ Supabase.
- `supabase/schema.sql`: الجداول وسياسات RLS وسياسة تخزين المرفقات.

تتيح مساحة `sendo-media` ملفات حتى 50 ميغابايت. المرفقات عامة للعرض في المنشورات، بينما الرسائل النصية خاصة. استخدم اتصال HTTPS؛ الميكروفون يحتاج إذناً من المتصفح. احمِ بياناتك ولا تنشر معلومات حساسة في المنشورات العامة.
